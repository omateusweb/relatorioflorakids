🔗 Importar da Nuvemshop
1
No painel da Nuvemshop vá em Configurações → Apps e integrações → Aplicativos parceiros → API e gere um token de acesso.
2
Cole o ID da loja e o Token de acesso abaixo.
3
Escolha o período e clique em Importar. Os campos do formulário serão preenchidos automaticamente.

⚠️ Por limitações de CORS do navegador, a importação direta via API pode exigir um proxy. Se não funcionar no navegador, entre em contato para configurarmos o proxy no servidor.
